# 念力飞车：共享空间训练版

本轮按用户提供的五维评审标准实现。目标是“把专注力反馈变成系统主空间里的悬浮飞车动作”，不是复刻完整网页赛车。本文不承诺星级。

| 维度 | 本轮交付 | 下一步验证或差距 |
|---|---|---|
| 创意性 | 空间停靠 + 专注力推进，玩家实际移动三维飞车 | BrainLink 尚未接入，目前是明确标注的模拟玩法 |
| 界面视觉 | 系统主空间保留；原生玻璃控制台、原生模式窗口；去品牌化飞车与喷流 | 真机观察字体、材质和尺度；当前飞车为桌面微缩尺度 |
| 交互体验 | 独立 Volumetric 飞车窗口与 Planar 控制台联动；捏合拖动、按钮操控、模式选择 | 未验证真机手势/手柄完整路径；尚无空间音频 |
| 功能设计 | 3/4/5 分钟三档停靠训练，5 个轮换目标；稳停判定、暂停、结算、重玩 | 12 分钟是设计时长，未完成真人完整试玩，不能据此宣称耐玩度达标 |
| 完成度 | APK、可构建源码、接口说明、来源记录、15 项功能测试 | 结果仅本次进程保留；公开开源和上架前需解决上游许可，并完成真机稳定性测试 |

## 运行结构

不再使用 Stage，也不再加载城市天空 GLB。默认窗口 FocusFlightVolume 为 2×1.2×2 米三维窗口，关闭其背景玻璃以让系统环境可见。飞车长约 0.324 米（默认车身放大 2 倍；移动坐标比例保持不变）；引擎逻辑坐标以 0.18 比例映射到窗口中心，拖动反向换算，速度/目标距离显示按实际尺度换算。系统允许移动和调整窗口，控制台默认在飞车窗口右侧，可能需要向右看。

FlightConsole、FlightInteraction 为独立 Planar 窗口，采用系统默认 Material.Regular。所有窗口包裹 PicoTheme；Option、Button、Slider 保持原生调色、状态和 hover，没有自绘根背景、色板覆盖或自定义 hover。主三维窗口的 materialbackground=0 是为了透明显示系统环境；两个平面窗口保留默认玻璃。

## 核心流程

1. 启动后可见系统环境中的飞车与右侧控制台。
2. 默认“专注力辅助”；可进入交互方式切换为空间拖动或按钮操控。专注力模拟滑条仅作反馈演示。
3. 选择悬停入门（3 分钟）、精准停靠（4 分钟）、专注巡航（5 分钟）。开始课程会复位飞车。
4. 将车中心移到蓝色目标环上方并悬停，连续停稳 1/2/3 秒记一次停靠，目标移到下一位置。光环低于目标中心，承托车身。
5. 计时结束或点击结束并结算后显示停靠次数、平均专注力与数据来源。无有效专注力时显示“—”，含任何模拟输入时标记模拟。
6. 暂停不消耗训练时间；选择模式期间计时暂停。可重新选择课程再玩。

## 验证

Gradle assembleDebug、testDebugUnitTest 通过。11 项飞行逻辑与 4 项训练逻辑测试通过，另有模板测试 1 项。训练测试覆盖稳停判定、窗口锁定与暂停计时、到时结束、模拟标记和缺失值平均统计。SpatialUI 样式检查 0 errors / 0 warnings。模拟器确认系统房间背景、飞车喷流及并排双窗口可见。没有完成自动空间指针点击、完整 12 分钟真人试玩、真实脑电设备、真机帧率或舒适性验证。
